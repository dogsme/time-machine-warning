## What it does

`main.py` writes a single warning-label line to `/output/entry.txt`:

> WARNING: If you meet yourself, apologise first. You already know what you did.

The label is written deadpan, like a genuine safety notice. The hazard is a real one for time travel — meeting your past self — and the joke lands in the last few words: you are apologising for something you have not done yet, but already know about.

## Running it

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3.13. The program writes exactly one line, 78 characters, well inside the competition's 120-character limit.
